My Internship Notebook

Privacy policy

Last updated: September 25, 2026. My Internship Notebook is a free, open-source application for tracking internship applications.

Data stored on your device

Your notebook, preferences, and unsaved recovery drafts are stored in your browser. Anyone who can use the same unlocked browser profile may be able to see that local copy. You can remove it by clearing this site's browser data.

Optional account and cloud sync

If you choose cloud sync, Firebase Authentication stores your account identifier, email address, sign-in provider, and authentication records. Google Cloud Firestore stores your notebook under your Firebase user ID. Security rules permit a verified signed-in user to access only the notebook whose ID matches that user's ID.

Notebook content can include companies, roles, dates, links, contacts, skills, notes, and status history that you enter. This service does not sell data, show advertising, or use notebook content for marketing.

Service providers

Google Firebase provides authentication and cloud database hosting. Its handling of service data is governed by Google's applicable privacy and security terms. GitHub Pages hosts the public website.

Retention and deletion

Local data remains until you clear this site's browser storage. Cloud data remains until you delete the account in Settings. Account deletion permanently removes the Firebase sign-in and its cloud notebook; it does not automatically erase copies stored in your browsers.

Security

HTTPS, Firebase Authentication, email verification, and owner-only database rules protect the cloud copy. This is not end-to-end encryption: the hosting provider operates the infrastructure that processes stored data.

Questions

For privacy questions, open an issue in the public project issue tracker. Do not include passwords, private notes, or other sensitive information in an issue.
