My Internship Notebook

Privacy policy

Last updated: November 13, 2026. My Internship Notebook is a free, open-source application for tracking internship applications.

Data stored on your device

Your notebook, preferences, and unsaved recovery drafts are stored in your browser. Anyone who can use the same unlocked browser profile may be able to see that local copy. You can remove it by clearing this site's browser data.

Optional account and cloud sync

Cloud sync is disabled unless this site's owner configures Supabase. If configured and you choose to sign in, Supabase Auth processes your email, password, account identifier, and authentication records. Your session stays in memory. Choosing Sync now sends or retrieves your notebook through Supabase's database API; Row Level Security restricts access to the signed-in owner's notebook.

Notebook content can include companies, roles, dates, links, contacts, skills, notes, and status history that you enter. This service does not sell data, show advertising, or use notebook content for marketing.

Internship listings and external links

The public internship feed is refreshed from the Pitt CSC and Simplify internship tracker during deployment; your browser downloads only the resulting public listings from this site. Using an Apply link opens a third-party employer or application website, whose own privacy terms apply.

Service providers

When configured, Supabase provides authentication and cloud database hosting under its applicable privacy and security terms. GitHub Pages hosts the public website.

Retention and deletion

Local data remains until you clear this site's browser storage. Signing out or disabling cloud configuration does not delete cloud data. The site owner can remove an account through the Supabase Dashboard, which also deletes its cloud notebook. This leaves browser copies intact. See the account deletion guide.

Security

HTTPS, Supabase Auth, and owner-only Row Level Security policies protect the cloud copy. This is not end-to-end encryption: the hosting provider operates the infrastructure that processes stored data.

Questions

For privacy questions, open an issue in the public project issue tracker. Do not include passwords, private notes, or other sensitive information in an issue.
