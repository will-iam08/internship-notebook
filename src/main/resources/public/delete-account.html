Delete your account

Local-only use has no account. To remove your local notebook, clear this site's browser data on each device. Download a backup first if you want to keep a copy.

If the site owner has configured Supabase cloud sync, signing out leaves your cloud notebook intact. Ask the site owner to remove your account and cloud data through their private support channel. Do not post account details or notebook contents in the public issue tracker.

For the site owner: open Supabase Dashboard → Authentication → Users, select the account, and delete it. The notebook row is deleted automatically with the account. This leaves copies stored in browsers intact.
